# Horse Racing Competition Platform

A modern web platform where users can compete in horse race betting, built with React and Vite.

## Features

- **User Authentication**: Secure login and registration system with Supabase
- **Horse Race Betting**: Interactive betting interface for horse races
- **User Competition**: Competitive betting platform for multiple users
- **Responsive Design**: Mobile-friendly interface with dark/light theme support
- **Real-time Updates**: Live race results and betting status

## Tech Stack

- **Frontend**: React 18 with Vite
- **Backend**: Supabase for authentication and database
- **Routing**: React Router v6
- **Styling**: Custom CSS with responsive design
- **Build Tool**: Vite with HMR and ESLint

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173) in your browser

## Project Structure

- `src/pages/` - Main application pages (Login, Register, Dashboard, etc.)
- `src/components/` - Reusable React components
- `src/lib/` - Utility libraries and Supabase client
- `src/hooks/` - Custom React hooks
- `src/styles.css` - Global styles and component styling

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
